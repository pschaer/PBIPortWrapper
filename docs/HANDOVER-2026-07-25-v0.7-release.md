## What's in v0.7.0 (since v0.6.0) — CHANGELOG highlights

- **Tray-first workflow (#47):** single **Off / Forward / Serve** model; **auto-serve
  on detection** driven by a per-model **On-detection** policy (Do nothing / Forward /
  Serve / Serve after grace period) with grace-period + ready/new-model toasts;
  auto-start silent to tray.
- **Serve-lifecycle consolidation:** one pure `ServeLifecycleMachine` (states×triggers)
  + a single `ServeLifecycleCoordinator` owning detection & exit. Fixed the
  exit-while-serving DB-restore regression (#100), the grace re-serve loop, and a
  startup UI-freeze (UIA probe moved off the UI thread).
- **Grid ↔ tray convergence (#88):** grid gained the **On-detection** dropdown and a
  **Network** toggle (both sync with the tray *both ways*); the separate Action + Serve
  columns became a single **Action** menu built from the same `AvailableActions` the
  tray uses. Tray gained the **Allow network access** toggle.
- **Auto-start with Windows (#87):** opt-in checkbox; `HKCU\…\Run` entry; launches
  silent to the tray; self-heals the Run key on exe move.
- **Detection fix (#94/#95):** resolve model names by AS port (works when the Desktop
  engine runs elevated).

## Release checklist for v0.7.0

Follow the same route used for v0.5.1 / v0.6.0 (mechanics + gotchas are in the
project memory `pbiportwrapper-workflow.md`; prior notes: `docs/release-notes-v0.6.0.md`).

1. **Branch** `chore/v0.7.0-release-prep` off `develop`.
2. **Version bump → 0.7.0:** `PBIPortWrapper.csproj` `<Version>`/`<AssemblyVersion>`/
   `<FileVersion>`; `pbiportwrapper.pbitool.json` `"version"`. (Grep `0.6.0` to catch
   any stray refs.)
3. **CHANGELOG.md** `[0.7.0]` entry (use the highlights above).
4. **`docs/release-notes-v0.7.0.md`** (mirror the v0.6.0 notes structure).
5. Optional: README roadmap tweak (mark v0.7 shipped, .odc → v0.7.1).
6. `dotnet build` 0 errors + `dotnet test` green; open PR → `develop`; **maintainer merges.**
7. **Tag on Gitea:** snapshot `main` from the merged `develop` tree via
   `git commit-tree develop^{tree} -p main -m "v0.7.0"` → `update-ref refs/heads/main <sha>`
   → annotated tag `v0.7.0`; `git push origin main` + `git push origin v0.7.0`.
   (The auto-mode classifier blocks `git rm -rf .`; `commit-tree` is the clean route.)
8. **Build assets** (convention in memory): single-file self-contained publish
   (`dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
   -p:IncludeNativeLibrariesForSelfExtract=true`) staged into `PBIPortWrapper-v0.7.0/`
   (exe + CHANGELOG + LICENSE + README + pbitool.json + Resources/app_icon.png) →
   `Releases\PBIPortWrapper-v0.7.0-win-x64.zip`; MSI via `Installer/build_installer.ps1`
   → verify MSI `ProductVersion 0.7.0.0`. Watch for a running `PBIPortWrapper.exe`
   locking the publish (Stop-Process it); build to a scratch `-o` dir if the
   maintainer's instance holds `bin` locks.
9. **Publish GitHub (maintainer):** `git push github main` + `git push github v0.7.0`;
   `gh release create v0.7.0 --notes-file docs/release-notes-v0.7.0.md`;
   `gh release upload v0.7.0 Releases\PBIPortWrapper-v0.7.0-win-x64.{msi,zip}`.
